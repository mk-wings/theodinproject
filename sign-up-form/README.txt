SIGN-UP FORM — The Odin Project practice

Files:
- index.html: page structure and form fields
- style.css: layout, colors, typography, responsive styles
- odin-logo.svg: local logo asset

How to run:
1. Extract this ZIP file.
2. Open the sign-up-form folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.

The photo and Google Font are loaded from the internet, so those two
external resources require an internet connection. The form layout itself
works without JavaScript. Browser validation checks required fields and
email format; matching the two password fields would require JavaScript.
